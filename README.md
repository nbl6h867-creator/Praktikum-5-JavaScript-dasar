# Tujuan Praktikum

Praktikum ini bertujuan untuk memahami dasar-dasar JavaScript dan penerapannya pada halaman HTML, meliputi variabel, tipe data, operator, percabangan, perulangan, function, manipulasi DOM, serta validasi form.

# Perangkat yang Digunakan

- Visual Studio Code
- HTML
- JavaScript
- Browser Mozilla Firefox
- Git dan GitHub

# Cara Menjalankan Program

- Clone atau unduh repository ini.
- Buka folder proyek menggunakan Visual Studio Code.
- Buka file index.html menggunakan browser atau ekstensi Live Server.
- Ikuti instruksi pada halaman untuk menjalankan setiap latihan.
- Untuk melihat hasil console.log(), buka Developer Tools dengan menekan F12, lalu pilih tab Console.

# Langkah Kerja dan Hasil Praktikum

# Latihan 1 — Menampilkan Output
Menggunakan textContent untuk mengubah teks pada halaman HTML dan console.log() untuk menampilkan pesan pada Console.

# Latihan 2 — Alert dan Prompt
Menggunakan prompt() untuk menerima nama pengguna dan alert() untuk menampilkan pesan. Program juga memeriksa apakah nama diisi.

# Latihan 3 — Function dan Operasi Aritmetika
Membuat function untuk menghitung penjumlahan, pengurangan, perkalian, pembagian, dan sisa bagi.

# Latihan 4 — Percabangan If–Else
Membuat program untuk menerima nilai mahasiswa dan menentukan status kelulusan. Nilai minimal 60 dinyatakan lulus.

# Latihan 5 — Percabangan Switch
Membuat program pilihan angka 1 sampai 5 menggunakan switch.

# Latihan 6 — Form Bilangan Genap atau Ganjil
Membuat form untuk menerima bilangan bulat dan menentukan apakah bilangan tersebut genap atau ganjil.

# Latihan 7 — Mengubah Warna Halaman
Membuat tombol yang dapat mengubah warna latar halaman menggunakan function dengan parameter.

# Latihan 8 — Checkbox Menu Makanan
Membuat daftar menu menggunakan checkbox dan menghitung total harga secara otomatis ketika pilihan berubah.
